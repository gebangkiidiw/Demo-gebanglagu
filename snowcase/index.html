Help

Panduan singkat memakai Gebang Lagu.

Cara pakai dalam 3 langkah

  1. Tambahkan kunci API — buka Settings, pilih jalur (Suno API / KIE AI / API Frame / Sunor), tempel kunci. Saldo langsung dicek otomatis.
  2. Siapkan lirik — folder lirik berisi lagu1.txt, lagu2.txt dengan format [STYLE OF MUSIC] lalu [LYRICS].
  3. Generate — buka Create / Generate, centang lagu, atur jalur & opsi & format output (MP3/WAV), tekan Mulai Generate. Hasil audio masuk folder output.

Dapatkan kunci API

  • Suno API — sunoapi.org/api-key
  • KIE AI — kie.ai/api-key
  • API Frame — console.apiframe.ai/signup
  • Sunor — sunor.cc/dashboard/api-keys

Tips

  • Beberapa kunci di satu jalur dipakai bergantian; kunci yang habis kredit otomatis dilewati.
  • KIE AI wajib memiliki Callback URL (sudah terisi default, bisa diganti di pengaturan lanjutan jalur).
  • Model versi & gender vokal bisa dipilih di halaman Create, tersimpan per jalur.
  • Klik nama file di hasil generate untuk membuka lokasinya.
  • Halaman Cover Musik bisa mengubah genre/vokal lagu existing jadi全新 (Cover, Mashup, Extend, dll).
